

## Conventions (added 2026-08-28 00:03)
- The 'navbar' the user refers to is the sidebar.tsx component in the canvas directory of the melon-web package
- Folder/canvas persistence data lives in .melon/canvases
- The project is a pnpm monorepo (pi workspace) with packages including melon-server, melon-web, and desktop

### Architectural Rules
- When a user requests a feasibility assessment, deliver a written verdict (possible/not possible/with caveats) before or alongside tool exploration, not after unbounded exploration
- For sidebar/navbar filesystem sync questions, propose a concrete mechanism (file watcher + invalidation event) and ask the user to confirm scope before implementing
- Limit consecutive exploratory tool calls to ~3-5 before pausing to report findings to the user
- When a tool call is malformed, acknowledge the error explicitly and retry rather than producing zero tool calls silently
